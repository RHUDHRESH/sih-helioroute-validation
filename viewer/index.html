What this comparison does and does not prove

Both controllers first serve local load from local PV. Only the remaining surplus can be shared. The solver is exact within this restricted two-path problem; it is not a global service-allocation optimizer. With capped grid backup, this restriction can leave a load unmet even when another network policy could serve it. Select “local_first_counterexample” to see that limitation.

Average real power only. No storage, pump/water model, export, AC voltage or current, MPPT, switching, protection timing, electrical stability, or hardware ratings are validated. Conversion efficiencies and capacities are synthetic assumptions. Optional standby is a dedicated grid-fed controller at B. Fault response is instantaneous at a simulation step.

The added link is extra hardware. A topology benefit does not prove control-algorithm superiority. The loss-aware greedy rule and restricted solver agree in this model.
